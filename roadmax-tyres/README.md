# RoadMAX Mobile Tyre Service Website

A modern, high-conversion React website for **RoadMAX Mobile Tyre Service**, built strictly according to brand specifications in **Light Mode**.

## Features & Sections Included

1. **Top Emergency Bar & Navigation Header**:
   - Live dispatch indicator: *"Mobile Service Active"*
   - Click-to-call direct hotlines: `04 1234 45 91`
   - Facebook Marketplace integration pill
   - Responsive desktop & mobile slide-out menu
   - Quick Quote pop-up modal trigger

2. **Hero Section**:
   - Prominent RoadMAX brand motto: *"GREAT TYRES. GREAT SERVICE. GREAT PRICES."*
   - Slogan: *"BUILT FOR THE ROAD AHEAD • WE KEEP YOU MOVING"*
   - Direct call button (`tel:0412344591`)
   - On-demand mobile service badge showcasing the equipped RoadMAX service van
   - **Interactive Quick Tyre Size Matcher Widget** (Select Width, Profile, Rim Size & Tyre Type for instant price checks)

3. **Services & Tyre Showcase**:
   - Mobile Tyre Fitting (Home, work, roadside)
   - Precision Computerized Wheel Balancing
   - New & Quality Used Tyres (Budget to Premium)
   - Emergency Puncture Repairs & Valve Replacement
   - Trade Accounts & Bulk Order Supply
   - Fleet & Commercial Van Support
   - Vehicle compatibility showcase (Passenger, SUV/4WD, Vans/Utes, High-Performance)
   - Top tyre brands ribbon (Michelin, Bridgestone, Goodyear, Pirelli, Continental, Dunlop, etc.)

4. **Call Now Section**:
   - Urgent high-contrast dispatch banner
   - Massive direct call button with phone icon: `04 1234 45 91`
   - 1-click SMS / WhatsApp quick messaging buttons
   - 3-step rapid service breakdown (Call -> We Arrive -> Back on Road)

5. **About Us Section**:
   - RoadMAX story & mission
   - Showcase flyer display (`tyres_flyer.jpg`)
   - 4 Core Pillars: 100% Mobile Convenience, New & Quality Used, Trade & Bulk, Precision Equipment
   - Key statistics: 15,000+ tyres fitted, 30-60m average response

6. **FAQ Section (FAAQ)**:
   - Interactive accordion covering questions:
     - How mobile tyre fitting works
     - Locations covered (driveway, workplace, roadside)
     - New vs. tested used tyres
     - How to read tyre sidewall size
     - Included wheel balancing
     - Emergency arrival times
     - Trade customer & bulk fleet discounts
     - Payment methods accepted

7. **Contact Us & Social Media Section**:
   - **Facebook Marketplace** prominent spotlight banner
   - Social channels: Facebook, Instagram, WhatsApp, TikTok
   - Direct dispatch line: `04 1234 45 91`
   - Interactive Booking / Quote Request Form with instant submission confirmation

8. **Footer & Floating Call Action**:
   - Complete light-mode footer with brand links & operating hours
   - Sticky floating bouncing call button with live pulsing status indicator on bottom right

## Running Locally

```bash
cd roadmax-tyres
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

## Production Build

```bash
cd roadmax-tyres
npm run build
```
Production output is located in `dist/`.
